# Reicon brand and flag assets

Generated from `data/brands.json` and `data/flag.json`.

These are **website assets**, not exports of `reicon-react`, `reicon-vue`, or the other framework packages. The generated `cdn/reicon-brands.js` bundle is for the website and prototypes. For application code:

- Use `reicon-file` for file and technology marks such as GitHub, Figma, React, Docker, and Vite.
- Use the official brand asset for a company logo with brand color and trademark rules.
- Use `data/brands.json` or `data/flag.json` only when the project already serves those assets.

Do not invent a brand component or import a brand from a framework package.
