# Reicon intent map

Pick by job, not by object. The **Icon** column is the exact kebab name; resolve the component in `CATALOG.md` or `scripts/icon-names.json`.

Prefer unnumbered names. Prefer core categories over `newicons`. When two icons fit, choose the one that matches the surrounding set.
